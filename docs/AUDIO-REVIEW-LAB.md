## 结果与失败保护

每个run保存请求、来源、实现快照/哈希、模型清单、依赖版本、冷加载/单窗/整run时间、实际原答或token、失败日志及outcome。文件独占新建，原始观察不可覆盖。新配置使用新版本文件；旧输入不因晚到材料或调参改变。

机器结果只能`proposal_only`，不能声明人类/Codex亲听、speaker/timing验收或accepted/default。模型输出截断、未完成case、资源不足和超时必须保留并计入覆盖。全零PCM的非空文字是控制失败；不得以总CER、平均分或多数票消掉关键错误。没有可信目标日语金标准时不计算日语准确率；合成控制成绩只代表该控制集。

可启用`zero_pcm_guard`，只对所有采样精确为零的窗口返回空机械结果，并记录`model_inference_performed=false`；它不是语音检测器，不过滤任何非零弱声。原始未过滤失败记录保留。相同音频/语言/模型清单/设备/精度/VAD/提問条件的完成试验按条件指纹拒绝重跑；显式重复必须给新的可证伪假设，不能以调换样本顺序或计数刷新绕过。未知运行锁优先保护。

实验有独占owner lock。未知/仍在运行的owner不因时间到期自动抢占；先确认进程和保存结果。普通单窗默认120秒，新增CPU参考可预登记180–300秒；整run有限上限30分钟。超时只终止本次worker，不动既有服务。GPU运行前核实际空闲预算；不足则`resource_deferred`，不强行清显存、卸载其它模型或悄悄换精度。模型取得与安装也采用有限请求、保存进度，不无限重复同一失败。

1. 原有Whisper相同冻结窗，CPU int8、日语、beam5、无前文，仅比较VAD。已有英文正/否定、静音对照。保留无VAD覆盖分支，不因VAD加速推断全片完整。

4. 仍漏多声部才试真正分离，先长度/延迟/串音/伪影/控制集；pyannote分段不能代替分离。已核文字才接强制对齐；保留原始时间预测与修复，80ms类别步长不等于误差保证。

当前MossFormer2适配器使用已下载、固定哈希的官方checkpoint，`torch.load(weights_only=True)`及严格全参数匹配；不调用会自动下载的构造器。短窗整段输入，保留实际模型输出尺度，仅做记录在案的防削波增益，不将两路都强行拉到输入RMS。两条输出是模型声源槽，不证明两位真实角色。当前合成分离指标不稳定、本片重识别未补核心词，暂不扩大整集应用。
5. 有真实质量增益后再整集影子运行及目标时间回映。覆盖、词句、发音、说话人、源歌词、字体/画面/播放器各有独立义务。机械采样往返不能证明AAC priming或真实声界。

每次迭代记录假设、唯一主要变量、输入/模型/代码/环境版本、结果、是否改善、剩余失败、下一退出/进入条件。旧失败重复无变化不重跑。新组件没有增益则停止扩大，不为安装投入赋予主审权限。当前没有可靠日语自然叠声盲测金标准，不伪造这一资源；合成日语最小对只能补基础诊断。
