## 个人范围与媒体保护

个人意愿、独立下载授权、来源映射、盘点、季集与实际集数是不同事实。只在 selected、有效个人状态、无 cleanup_hold 且原授权/映射/盘点/逐集边界有效时推进对应操作。目录发现或收录不改变个人意愿与下载授权。

wish/trial 做首集实评与一集一版稳定更新；watching 才持续制作洁净保真原片加逐集自制字幕。不扩大旧番/整季回补。原片、原稿、历史、已看、在途与未知任务保留。

广告发布源和已声明 AI 加工源按持久规则过滤；过滤不新增“源已封禁”分集占位。RAW、MKV、发布者名、分辨率或码率不能证明洁净或保真。跨站同 hash 去重，实际 torrent 身份、明确续作季号及选集通过后才能提交。

既有 127.0.0.1:4870 qB 是后台唯一提交入口；不定时操作桌面、不因离线自动启动/切换实例。旧迅雷任务与未知弹窗/committing/回执先核对，不能跨下载器盲目重投。

## 字幕制作和版本

日文对白准备、v0→v1及缺件归档前执行 [逐集日文来源](SUBTITLE-JAPANESE-SOURCES.md)，实际查本地轨、Jimaku与用户来源；候选、检索故障、目标匹配及亲听分开。中文首版仍可先交，但必须明示日文对白缺口，不以歌词/文件名/edition宣称完整双语；新稿沿原owner受控增量修订。

每集一个正文 writer，整体一集主动生产；调度只准备、派发、跟踪。先完整可看 v0，再由同一负责人立即继续 v1。v1 实际处理 screen_text、op、ed、placement、effects、semantics 六项；具体无解项保存尝试、证据、现版处理及下一新条件后归档，不能整类跳过。

v0/v1 的常规预算分别为 60–90 分钟，不是无条件时限。finished 表示完成观看交付，正式 accepted 只记录真实全面审校；未审听、静音播放、ASR/OCR 或报告字段均不能制造验收。

edition 表示制作层级，磁盘 version/release ID 表示不可变产物。旧目录叫 v1 的基础版可在索引标 edition=v0，但原 ID/目录/hash 保留；精校必须生成新物理版本，不能改标签冒充工作完成。

领取、继续和输出前核逐集 watches.finished。已看不自动回修或 experience；中途变已看则保存并安全停止。停止的旧 writer 不自动唤醒；只有宿主已核停止与基线并返回 isolated_owner_required 的任务才可依返回动作另建私有修订负责人。

对白中文上、日语下，每语言一行；长句按真实语义和声音边界拆分，不均分时长、不挤字。白字与柔阴影是当前偏好，实际字体 family、字重、libass 选字和文件 hash 必须核实。歌词主动寻找，缺可靠日文不编造；字卡候选不能替代实际发音。

2026-10-16位置偏好：1920×1080、中文64/日文46的普通对白，中文y=990、日文y=1036；同比缩放，核实际字面间隙和底边余量。字卡、上方避让及特殊场景独立处理，历史成品不批量改写。

## 成品入口、续播和已看

`finish_subtitle_episode.py` 产生不可变成片，`publish_finished_episode.py` 登记同一 `static/finished-media/index.json`。核真实作品 ID、季号、本地集号和 edition；首页、全部追番及作品分集必须能打开成品，不能仅交文件或字幕库记录。v1 完成优先、v0 可选，活动播放不强换，不回填 episodes 或伪造 accepted。

`/api/finished-viewing` 保存服务端进度，以不可变 release ID 和视频 SHA 绑定。实际播放后每 15 秒、暂停、页面隐藏/关闭时保存；只打开或未播放拖动不写。续播优先原观看版本，新版不继承旧版时间，已看重播从头开始；历史未保存进度不猜测回填。

看完/未看共用原 watches、shows.watched 与完成边界规则；结束后显式确认，seek/ended 不自动已看。会话序号拒绝迟到覆盖，播放租约按同作品本地集号保护。核验进度用隔离库，不污染真实观看记录。
