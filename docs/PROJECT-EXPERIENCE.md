# 项目经验与已知边界

这些结论来自本项目已保存的开发、字幕交付及研究记录；原始媒体、听审材料、截图与逐次实验回执在本机私有目录。本文是经验索引，不新增验收，也不把一次成功当成普遍能力。当前执行顺序见 [项目规则](PROJECT-RULES.md)。

## 交付要以能看为终点

早期把单个叠声、技能读音和全面审听放在所有输出之前，导致反复研究却长期没有完整成品。改为 v0 先完整可看、同一负责人紧接 v1 六项精校；疑点随版本记录。完整输出、解码、实际入口和播放器验证必须发生，不能用工作稿字数或截图数量代表交付。

finished 与 accepted 分开后，可保留诚实的质量边界，同时让用户先看。可靠日文缺失处允许中文，不能为了双语齐全编造日文。v1 主动补画面字、歌词、位置、必要动效及语义，不能把“首版快交付”理解为永久省略这些工作。

## 原稿与证据必须可追溯

每集重新盘材料，保存原始字节、声明署名、媒体和原稿 hash。简繁、重包装、同一压缩流和同文轨不能算独立译者。晚来的新稿先归档、做文本差异，只处理真实改动；活动输入与已有成品保留。

ABEMA、CR、巴哈等版本可能有不同片头、广告、剪辑和时间轴。累计 E14 可能是本地 S02E02，不能凭标题数字或均匀平移绑定。字卡词形可解释术语，但不能证明同一词第二次实际发声；第一次 call 不能替代第二次声音证据。

## 模型结果只是候选

本地 Whisper、Qwen、Gemma、Ruby、分离和 ICA 实验曾出现叠声漏词、技能误读、静音幻觉、声部分离一好一坏等问题。多模型一致不代表独立裁判；合成最小对成功不等于真实混声通过。CTC 候选分差不应转成正确概率。

原声检查把词形、读音、语义范围、起止点分别记录。参考与目标重叠或身份未核时不能当独立参考。先做控制样本和零 PCM，控制失败则按预登记停止；未实际执行目标不能写成“已在本片失败”。没有新输入/实现/假设就不重复旧实验。具体阻塞保存在 issues.json，周复盘只处理新条件。

## 排版要看实际字体与连续区间

fontsdir 存在文件不等于 libass 使用了字体。核 legacy family、OS/2 字重、PostScript 选字及文件 hash，保留实际 font selection 报告。当前局部 Noto SC/JP Medium 500 和中文64/日文46只是一套候选配置，不能当通用护眼标准或批量套用其它稿。

中文上日文下各一行，保留 parent/child、原文覆盖与切点依据。不能机械均分时长、缩字挤字或堆四行。原稿竖排/旋转标签要先理解意图，不能只换字体就保留变换。白字前层保持清晰，柔影放后层；亮背景、嘴、技能框和叠声必须在本集实帧检查。

静帧用于识字与布局，运动/切镜要看事件区间。全尺寸和 640px 都检查；seek 后核实际 PTS，避免误把前一帧当目标。静音倍速播放至 ended 能证明部分技术链路，不能证明原声听核、逐句语义或实时 native video 能力。

## 播放是业务状态的一部分

独立播放器与字幕库成品出现后，曾存在首页仍按原 episodes 误报缺集、成品进度只在浏览器等不完整链路。现在通过 FinishedReleases 合并成品与观看状态，通过 finished-viewing 写服务端，并把版本选择、续播与已看规则统一到正常入口。

视频结束与 seek 都不能自动制造已看；暂停、隐藏与关闭可能产生迟到请求，须用会话序号和租约保护。不可变版本时间不能互相继承。测试必须使用临时库和假媒体；实际入口检查阻断写入，不拿用户观看历史当测试数据。

## 调度要短，制作要连续

逐句轮转 heartbeat 容易让任务重复读历史、只改少量正文；改为准备调度加独立整集 owner。先记录意图，再外部派发并确认真实 threadId。unknown/committing/有效 lease 不是“超时即可重试”，先核回执才安全。

长会话累积工具输出和图片会增加活动上下文；rollout 文件大小不等于单次请求大小。2026-10-15 的两条调度真实停在模型 HTTP 等待，工具已经结束。精确 turn 中断与真实 compact 恢复了进展；它不证明网络根因全部修复。调度轮次通常 3–10 分钟，做完就结束；整体制作不受这个轮次预算切碎。

项目压缩阈值与工具输出上限只是上下文管理配置。独立守卫只处理指定调度 heartbeat 的无进展轮次；不能杀整个应用、改数据库状态、唤醒停止 writer 或自动释放业务租约。具体限制见 [调度健康](CODEX-DISPATCH-HEALTH.md)。

## 开发和运行分开验证

列表性能用单请求只读快照和批量查询，避免逐作品重复连接；不能以跨请求缓存掩盖观看/文件状态变化。目录分页按实际返回条数推进，检查重复、空页与完整性；资料导入不产生下载授权。

qB 优先与持久 intent、同 hash 去重、实际文件清单核验必须贯穿选源、字幕材料和最终点击。下载完成不等于已看；封禁是过滤规则，不应在页面新增占位。测试使用临时 DB/FakeDownloader/MemoryVault，不能为了验证启动第二个生产 Engine 或读取真实账号凭据。
