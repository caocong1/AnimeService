# 番剧熟肉交付流程

2026-10-14 用户最新要求：制作的终点是能直接观看的完整一集，优先持续产出、速度和效率。少数未核词、模型识别失败、歌词缺日文、缺全片亲听能力，不再把整集卡成永远未完成。本规则覆盖旧文档与字幕 skill 中把全面审校作为首版交付前提的安排；未做的审校仍如实记录。

## 每集的完成标准

完整视频、有完整可读中文、能播放和定位、没有已知明显缺段/严重遮挡/整段失轴，即可交付 v1。可靠日文齐全的对白采用中日双语；缺可靠日文的部分保留中文，禁止为了凑双语编写日文。

交付文件是字幕烧录 MP4、原片可用的 ASS 与字体包、简短版本说明。成品出现在字幕库的“可观看”筛选及“播放成品”入口，也留在本地媒体目录。用户不必查研究目录或读实验报告才能看动画。

`finished` 表示完整观看交付已经完成；实际逐声/语义审校是否完成单独记。未核疑点保留在版本说明，不阻止发布这个本地观看版本，也不把该集一直占在主制作槽。旧 accepted 记录不能伪造；原片、旧字幕、观看状态及活动播放继续保留。

## 一次做到交付

1. 核对这一集及现有目标视频，复用已有完整基稿、术语和字体；不为新一集重搭环境。仅中文主稿也可先完成，不无限等待第二译者或日文歌词。
2. 连续处理整集文字，集中修正遗漏、明显误译、名字/数字/否定和阅读障碍。有歧义先取现有可靠基稿中最稳妥、与语境一致的表达，记录理由。
3. 疑点集中处理一次，默认不超过10分钟；没有新增可靠依据就落定本版表达并记修订项，将实在解决不了的问题存入 `data/subtitle-studio/unresolved-issues/issues.json`。不要轮换模型、重复相同截窗或用安装进度代替字幕成果。首版制作期间不开展模型研究。
4. 一次集中检查覆盖、时轴范围、测宽、字体和几个真正有风险的画面；复用未变素材的有效检查。实际发现的坏文件、字幕大段缺失、严重错位等影响观看的问题当轮修好。
5. 整集输出并核时长、音视频解码、原音轨、播放/暂停/跳转和下载入口。通过后即交付并释放制作槽；本轮不要停在“报告写好了”。
6. 晚到基稿或新反馈只修改相关部分，发布 v2，保留 v1。已交付集不因为还有审校备注被撤回重做。

可靠材料已齐时按一次连续会话完成首版，不用定时任务切碎生产。60–90分钟是首版工作预算目标，不是无条件耗时保证；耗时记录区分新字幕制作、编码和重复返工。受单点拖延时缩减装饰、研究及非必要日文补全，先保住整集交付。确实没有完整可用材料时记录具体缺件，并转下一集可操作材料，不能假称生成了视频。

## 已落地的快速出口

`scripts/finish_subtitle_episode.py` 读取固定的媒体/ASS/字体 hash 配置，生成整集烧录 MP4、外挂包和版本说明，自动核全片解码、时长、音轨包 hash 和实际选字。已完成且输入相同则复用；输出不同必须另建版本，不覆盖旧版。进程有独占锁和执行时限，只结束自己的超时子进程。

`scripts/publish_finished_episode.py` 将完成文件登记到本机字幕库，提供播放、下载和说明，使用硬链接保留私有原始输出。登记不改生产数据库、原视频或旧默认，也不重启服务。静态成品目录排除 Git，沿现有设备访问保护提供给用户；不公开上传。

```text
python scripts/finish_subtitle_episode.py 本集固定输入配置.json
python scripts/publish_finished_episode.py 本集成品目录 --series-title 作品名称 --library-dir 本集媒体目录/自制熟肉
```
