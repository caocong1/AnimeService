# 想看首集实评与稳定更新

## 当前规则入口

在现有AnimeService项目（保留原项目与运行目录，不替换这些字段）及原目标聊天运行。先读AGENTS.md最新规则、docs/VIEWING-WORKFLOW.md、SUBTITLE-DELIVERY.md、CODEX-DISPATCH-HEALTH.md和PROGRESS/HANDOFF最新短交接。通过现有`/api/viewing-workflow`或只读`viewing_queue.py --lane wish`取当前队列；只处理selected、wish/trial、无cleanup_hold且原授权、映射、逐集边界与研究政策有效者。watching的字幕材料准备/派发交任务2，不改个人或已看状态来取得范围。

## 本轮有界清单

1. 通常3–10分钟收束，10分钟后不启动新重活。比较候选/完成回执、材料版本、主备/分集与具体未决问题指纹，先取低成本事实。输入未变就结束，不每小时解同一字幕、重做全媒体hash、开同SHA图集或重读长报告。
2. 回读现有download_gaps分类与检查时间，分清source_not_found、download_retry、primary_window、质量/核验阻塞与sources_disabled。诊断ready不是文件完成；旧缓存须标明陈旧并核现有后台。发现/下载/完成对账由唯一现有Engine处理，本任务不直接调用写缓存/ingest函数、实例化Engine或强制抓源。已设wait_hours和核实发布窗口才可据实判定等待；未知发布时间不判逾期。
3. 有真实变化且材料齐时选一部首集，完成一个可恢复的实物评审批次。保存准确视频/字幕版本、实际覆盖区间、已完成判断、未核项和下一游标；沿现有审阅入口保存并回读。尚未完整实看/实听不能给整集完整评分或宣称全片洁净；不以片段填全集报告。若现有工具不支持可靠断点或需超预算整片工作，记录一次具体能力缺口并转owner安排，不擅自创建另一个制作writer或在定时轮无限延长。
4. 对已完整评审的首集，按原归属入口登记合格可看及实际主源/备选，不能把发布者当翻译者。未知保真、中文/可靠日语和实际听核缺口分别留证；不把技术解码/字幕存在当亲听。真实完成的首集及时进入可看链路，后续一集一版沿原主源规则更新。
5. 守卫仅针对白名单中的调度轮次。先读status.json的时间与error，再按本调度聊天/精确turn筛actions.jsonl控制尝试及结果，并核实时队列；不把全局末条、缺action或IPC成功当成业务完成/未创建证明，不自行--apply、中断、清锁或重放整轮。保存本轮已完成动作与下一触发条件后结束，不常驻等待。

## 停止与安静条件

输入/问题未变、重试或主源窗口未到、已有owner活动、旧失败无新条件时安静结束。工程问题仅临时DB/假下载器隔离分析，真实动作留受控入口；不在本任务内修生产。仅新合格首集、真实主备变化、新实质观看失败或明确用户操作通知，按对象/输入版本/原因去重。PROGRESS/HANDOFF只追加简短结果与私有证据引用，保留并发内容；没有现成游标持久入口时不能自建业务表或改调度配置。

## 禁止事项

不扩大授权、不改观看/个人状态、不回修已看、不唤醒停止聊天、不绕过广告黑名单、AI保真、真实torrent/hash/manifest/单集归属/跨站去重门禁；未知提交、committing、租约、dialog_hold和其它owner均保护。不写逐句字幕、不接管正常v0/v1。只用现有动画下载后台，不启动或切换下载器、不建第二Engine、不服务重启、不Computer Use、不付费/音视频外传，不改任务/提示词或生产开关，不删除/替换旧文件，不用片段伪造整集验收。
