# 放映室片段导出

在放映室「截图」旁点击「截取片段」。使用原片预览的位置按钮、时间输入或两条时间滑杆选择开始与结束，点击「播放所选片段」检查范围。时间支持秒数、分:秒、时:分:秒以及毫秒。也可把主播放器当前位置设为开始。

勾选「裁剪画面区域」后，在暂停的预览上拖选矩形，或填写原画面像素坐标及区域尺寸。输出宽度有原尺寸、1920/1280/960/640/480/320及自定义；高度保持区域比例，MP4为编码需要对齐偶数像素。帧率可保留原值或指定；MP4另有三档画质。

MP4可包含或关闭音频，并选择文件内的音轨。默认跟随打开面板时的播放器选择，未明确选择则使用文件默认音轨。播放音量与静音不改变导出音频。GIF始终无声，可指定5–30fps和是否循环。

导出仅包含源视频画面、片内硬字幕和所选音轨，不合成网页软字幕、弹幕及网页画质效果。HDR暂不支持转码，明确报错；原视频不改写。主播放器在打开面板时暂停；独立预览不写观看进度、不标记看完。导出在本机后台执行，关闭面板后继续；完成可在面板预览并下载，刷新页面后可恢复本浏览器最近任务。

边界：MP4最长300秒、GIF最长30秒；单文件最多512MiB，导出目录限8GiB，可用空间至少768MiB；每次只运行一个导出，最长执行10分钟，转码限制线程。GIF最多1280×720等效像素，建议480/640宽。输出保存于数据库同级 `exports/clips`；用户下载是独立副本，无自动删除完成导出。取消只结束对应转码并清理自己的未完成导出，不操作原媒体。服务重启后未完成任务标记中断，不自动续跑；已完成片段可重新下载。

API使用当前会话、Origin及媒体盘点/大小/黑名单门禁：`GET/POST /api/web/media/{id}/clips`，`GET /clips/{job}`，`POST /clips/{job}/cancel`，`GET /clips/{job}/file`（`?download=true`附件下载）。请求只接受时间、尺寸、裁剪、格式等结构化选项，不能指定原路径、输出路径或任意FFmpeg参数；任务与媒体ID绑定。启动及编码结束核验源指纹，状态与下载重查媒体可见性。任务元数据不含源路径；FFmpeg错误文本不返回客户端。

实现依据：[FFmpeg输入定位与时长](https://ffmpeg.org/ffmpeg.html)、[crop/scale/palettegen/paletteuse过滤器](https://ffmpeg.org/ffmpeg-filters.html)。使用重编码精确截取和GIF调色板；输入与输出均限制片段时长，GIF调色板不会读取所选片段后的整集内容。不把关键帧码流复制作为精确切点保证。

验收：`tests/test_clips.py` 23项隔离测试（真实合成视频转码、首帧像素比对、尺寸/时长/音频、循环、取消无输出进程、重启、源变更、会话/媒体/黑名单），相关播放回归38项、音轨/画质/网页回归50项通过；JS新增2项与原截图1项通过。Headless Edge对独立临时数据库、合成视频和假分集/弹幕完成拖选、MP4/GIF导出/预览、下载入口、Escape焦点及390/320/768无横向溢出，未控制用户桌面或调用生产下载器。截图及记录位于本机 `.design/clip-export/build`。
